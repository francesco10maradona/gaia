## Pubblicare su GitHub Pages
1. Crea un repository su GitHub.
2. Carica i tre file nella root del repository.
3. Vai in **Settings → Pages**.
4. Seleziona **Deploy from a branch**.
5. Scegli `main` e `/ (root)`.
6. Salva e attendi la pubblicazione.

Nota: le risposte vengono salvate localmente sul dispositivo di Gaia. Per riceverle automaticamente anche sul tuo dispositivo serve collegare un servizio di form/backend.
